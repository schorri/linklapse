## LinkLapse v0.1.0

Track intermittent Wi-Fi and Internet problems from a Windows laptop, with a dashboard you can start and stop directly.

### Get started

Download **LinkLapse-Windows-v0.1.0.zip**, extract it completely, open **LinkLapse.exe**, choose a duration and click **Start monitoring**.

Windows 11 with its built-in Windows PowerShell 5.1 / .NET Framework 4.8. No additional runtime installation or administrator rights for ordinary monitoring. The initial build is unsigned.

### Included

- Wi-Fi quality, gateway and multiple external tests on a shared timeline.
- Separate VPN/LAN routes, cautious ping qualification and bounded path discovery.
- Optional short download samples with load limits.
- Local CSV, standalone HTML and ZIP reports.
- English/German UI, responsive charts and print/PDF support.
- Compact overview, collapsible supporting details, explicit chart units and interactive measurement values.

This is the first release candidate. Functional and short integration checks have passed; additional long-run results from home networks are welcome. A missing ping alone does not prove an outage, and an AP without a known management address cannot always be tested separately.

Normal monitoring leaves Windows Update alone. An optional advanced private-laptop setting requires administrator approval and also pauses automatic security updates; read the guide before using it.

Report reproducible issues with private details removed. Checksums are in **SHA256SUMS.txt**.
