# Changelog

## 0.1.0

First LinkLapse release candidate.

- Portable Windows launcher with all ordinary setup, start/stop and report controls in the browser.
- Wi-Fi, gateway and multi-target Internet observations, separate VPN/LAN paths and bounded topology discovery.
- Qualified ping baselines, optional bounded download samples, local CSV and shareable HTML/ZIP reports.
- English/German UI, responsive charts, evidence dialogs and synthetic demo.
- Chart axes with explicit units, adaptive label sizing, interactive values and separate download-sample markers.
- Compact session toolbar, overview navigation and collapsible network paths, incidents and supporting details; exports retain the detailed report view.

Earlier internal prototypes used the working name Connection Monitor. No public release history or compatibility guarantee is implied by those prototype version numbers.
